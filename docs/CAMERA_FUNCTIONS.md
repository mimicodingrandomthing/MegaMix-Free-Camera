# Camera Functions

Addresses below are RVAs for the executable version used during development.

| RVA | Function | Role |
|---|---|---|
| `0x2FB0F0` | `FUN_1402FB0F0` | Per-frame camera update |
| `0x2FB410` | `FUN_1402FB410` | Projection/frustum-related calculations |
| `0x2FC3A0` | `FUN_1402FC3A0` | Camera basis/view transform |
| `0x2FB760` | `FUN_1402FB760` | Position setter |
| `0x2FB780` | `FUN_1402FB780` | Interest setter |
| `0x2FB7A0` | `FUN_1402FB7A0` | Roll setter |
| `0x2FB7B0` | `FUN_1402FB7B0` | Camera state/up-vector related setter |
| `0x2FB860` | `FUN_1402FB860` | Rotation getter |
| `0x2FB960` | `FUN_1402FB960` | Position getter |
| `0x2FB980` | `FUN_1402FB980` | Interest getter |
| `0x2FB9D0` | `FUN_1402FB9D0` | FOV getter |
| `0x2FB9E0` | `FUN_1402FB9E0` | Near clip getter |
| `0x2FBCB0` | `FUN_1402FBCB0` | Frustum test |
| `0x45DFC0` | `FUN_14045DFC0` | Culling caller |

These values should be treated as research notes, not universal addresses for every game build.
